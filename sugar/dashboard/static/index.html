    Limitations

      What this view can and cannot prove

      read-only · no mutations

      Can show

      • Observed runtime inventory in the selected scope: models, harnesses, tools, MCP servers and artifacts seen in the event spine.
      • First/last seen timestamps, event counts, projects and evidence links back to traces.
      • Harness telemetry fidelity and coverage levels L3–L0 for each harness.
      • That tamper-evident audit exports can be produced with the CLI.
      • A downloaded package's SHA-256 (and optional HMAC signature) matches its package manifest when verified offline.

      Cannot show

      • A complete or declared inventory — absence here does not prove absence.
      • Model weights, training data, licenses, datasets or suppliers.
      • CycloneDX/SPDX certification or any standards attestation.
      • Approvals or policy decisions not recorded in the event spine.
      • That a package is complete outside the selected project/date scope, or that an auditor accepts the format.

      Export for an audit

      Download a scoped zip here (events + manifest, tasks, evidence, traces, AIBOM, coverage, claims and a README, all hashed in a package manifest). The download is local and read-only. Verify the package offline before sharing; an HMAC signature proves the holder of the key vouched for it.

      sugar audit package --out audit-package --project sugar --since 2026-11-01
      sugar audit verify-package audit-package
      SUGAR_AUDIT_HMAC_KEY=... sugar audit package --out audit-package --sign-key-env SUGAR_AUDIT_HMAC_KEY
      sugar audit export --out audit/2026-11.jsonl
      sugar audit verify audit/2026-11.jsonl audit/2026-11.manifest.json
      sugar aibom --project sugar --since 2026-11-01 --json
      CLI commands run outside the dashboard. The download above uses the same package builder; verify the zip offline with sugar audit verify-package <dir> before sharing it.
